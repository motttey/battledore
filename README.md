# Battledore

羽根突きゲームです。マウスで位置を合わせて羽根を打ち返します。

## キャラクター設定

開始画面で選んだキャラクターごとに、羽根の軌道と操作感が切り替わります。
設定は `sketch.js` の `characterProfiles` にまとまっており、各キャラクターについて次を調整できます。

- `flight`: サーブ・自分の返球・相手の返球の高さ、速度、横風
- `player`: 可動範囲、返球できる距離と高さ
- `imagePaths`: 通常時・打球時・羽子板の画像パス（現在は全キャラクターで共通）

## 起動方法

プロジェクト直下で次を実行します。

```bash
python -m http.server
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開いてください。
